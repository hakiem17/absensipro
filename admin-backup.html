Backup Data

Unduh seluruh data database (Acara, Peserta, Notulen, Master TTD) dalam format JSON. File ini dapat digunakan untuk memulihkan data di kemudian hari.

Backup mencakup semua data teks. File fisik (gambar/dokumen) di Storage tidak ikut ter-download.

Restore Data

Pulihkan data dari file backup JSON. PERHATIAN: Proses ini akan menimpa data yang ada jika ID-nya sama.

Pastikan format file valid. Tindakan ini tidak dapat dibatalkan.
Memproses restore...
Catatan Penting & Panduan
  • Backup dilakukan secara manual. Disarankan melakukan backup secara berkala setiap selesai acara penting.
  • Restore akan mencoba melakukan Upsert (Update jika ada, Insert jika belum).
  • Relasi antar data (Foreign Keys) akan ditangani otomatis, namun pastikan file JSON utuh dan tidak dimodifikasi manual.
  • Jika terjadi error saat restore, cek console browser (F12) untuk detail log.
